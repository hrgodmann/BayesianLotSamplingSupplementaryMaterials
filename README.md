# Bayesian Lot Sampling: Supplementary Materials

accompanying the article:
No Data Left Behind - A Primer on Bayesian State-Space Models for Acceptance Sampling

Authors: Henrik R. Godmann, Lotte Mensink, Ruud Wetzels, Eric-Jan Wagenmakers

Correspondence concerning this supplementary material or the main manuscript should be addressed to Henrik R. Godmann, Department of Psychological Methods, University of Amsterdam, Nieuwe Achtergracht 129, Amsterdam, The Netherlands. E-Mail: hrgodmann@gmail.com / h.r.godmann@uva.nl.

This repository contains: Appendix A (Extended results), Appendix B (Model validation following the principled Bayesian workflow), R code, and simulated data, accompanying our primer on Bayesian acceptance sampling using state-space models.
